<section style="background:#FFFFFF"><div class="imp-wrap"><div class="imp-sec-head imp-rv"><div class="imp-idx"><b>01</b> The problem</div>
<h2>The standard data loader knows record IDs. Your spreadsheet does not.</h2><p class="imp-lead">Every bulk import runs into the same wall. The CSV has an account name, an email, an external code, but Salesforce wants an eighteen-character ID, and nothing in the file has one.</p></div>
<div class="imp-g3"><div class="imp-card imp-rv"><div class="imp-xm">&#10005;</div><h3>Manual ID lookups</h3><p>Export the parent records, VLOOKUP the IDs into your file, hope nothing shifted between the export and the import. Repeat for every lookup field.</p></div><div class="imp-card imp-rv"><div class="imp-xm">&#10005;</div><h3>Silent duplicate creation</h3><p>Matching on one field alone creates a second record whenever the value is slightly different, and you only find out weeks later during a report.</p></div><div class="imp-card imp-rv"><div class="imp-xm">&#10005;</div><h3>Opaque failures</h3><p>An import fails partway and returns an error file that has to be reconciled against the original by hand before you can retry it.</p></div></div><p class="imp-pull imp-rv">A load that should take ten minutes turns into an afternoon of spreadsheet surgery, and the risk of a bad import lands on whoever ran it.</p></div></section>
<section id="what" style="background:#FBFCFD"><div class="imp-wrap">
<div class="imp-sec-head imp-rv"><div class="imp-idx"><b>02</b> What it is</div><h2>A loader that resolves the lookup for you, at import time.</h2><p class="imp-lead">Point it at a CSV, tell it which fields identify a match, and it resolves the related records as it loads. The mapping step that used to happen in a spreadsheet now happens inside Salesforce.</p></div>
<div class="imp-flow imp-rv"><div class="imp-node"><div class="imp-node-ic">&#9671;</div><h3>Your CSV file</h3><p>Headers are read and auto-mapped to fields on the target object, so most imports need no manual mapping at all.</p></div>
<div class="imp-lnk"><div class="imp-lnk-l"></div><span class="imp-lnk-t">Auto-mapping</span><span class="imp-lnk-t">Dynamic lookup</span></div>
<div class="imp-node"><div class="imp-node-ic">&#9737;</div><h3>Your Salesforce org</h3><p>Lookups are resolved dynamically, matching runs across the fields you chose, and records are inserted or upserted.</p></div></div>
<span class="imp-flow-note imp-rv">Matching runs on multiple fields at once, so near-identical values do not quietly become a second record.</span>
<p class="imp-lead imp-rv" style="margin:50px auto 0;text-align:center;max-width:72ch">It stays a data loader on purpose. Nothing proprietary sits between your file and your records, so what lands in Salesforce is exactly what you can see in the preview before you run it.</p></div></section>
